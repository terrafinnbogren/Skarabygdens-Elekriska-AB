# Skarabygdens Elektriska

Plattformen för Skarabygdens Elektriska AB: den publika hemsidan
skarabygdensel.se och, efter hand, interna verktyg för personalen.

| Mapp | Innehåll |
|------|----------|
| [`hemsida/`](hemsida/) | Den publika sajten – se [`hemsida/README.md`](hemsida/README.md) |
| [`funktioner/`](funktioner/) | Kommande funktioner: erbjudanden, uthyrning, admin och (parkerad) betalning |
| [`expertis/`](expertis/) | Fakta per område: el, mätning och kontroll, nätverk och säkerhet, energi, smarta hem, vitvaror, uppdrag |
| [`drift/`](drift/) | Hosting, domän, DNS, e-post och konton |

Varje mapp har en `CLAUDE.md` med syfte, nuläge, beslut och öppna frågor för
just den delen. Innehåll som saknas inför lanseringen står i
[`hemsida/INNEHALL.md`](hemsida/INNEHALL.md).
